# Visión

Construir el primer sistema capaz de comprender el funcionamiento operativo de un estudio jurídico.

Second Chair observará cómo trabaja el estudio, aprenderá sus procesos, construirá una memoria del contexto, detectará fricciones, propondrá mejoras y automatizará únicamente aquellos procesos que hayan demostrado ser óptimos.

No será un gestor de expedientes.

No será un chatbot.

No será una simple inteligencia artificial.

Será un colaborador que evoluciona junto con el estudio jurídico.
